# 番外 2：训练踩坑排查清单

遇到问题先按这条总纲定位到"数据 / 配置 / 资源"哪一类，再对症下药。

## 坑一：训练不收敛（loss 横着 / 震荡 / NaN）

- [ ] 标签格式对不对？坐标是否都在 0~1 之间、类别序号从 0 开始
- [ ] data.yaml 路径和实际目录是否一致
- [ ] 图片和标签是否同名（cat.jpg ↔ cat.txt）
- [ ] 学习率是否太大（NaN / 震荡时，lr0 先调小 10 倍）
- [ ] 数据有没有大量错标、漏标、损坏图

排查顺序：**先数据 → 再学习率 → 最后怀疑模型。**

## 坑二：CUDA out of memory

- [ ] batch 调小（16 → 8 → 4）
- [ ] imgsz 调小（640 → 320）
- [ ] 换更小的模型（l → s → n）
- [ ] 开混合精度 `amp=True`
- [ ] 关掉其他占显存的进程

## 坑三：框预测异常

| 症状 | 最可能的原因 |
|---|---|
| 满屏都是框 | NMS 没生效或 IoU 阈值太小 |
| 一个框都没有 | 置信度阈值太高，或类别序号错 |
| 框的位置全偏 | 标签坐标没归一化 |
| 框对但类别全错 | data.yaml 的 names 顺序和 class_id 错位 |

## 通用心法

1. 先复现，别在偶发现象上瞎猜
2. 二分定位，每次只改一个变量
3. 拿 10 张图、1 个 epoch 先跑通，再放大规模
